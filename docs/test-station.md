# Dedicated test station

Run the updated controller and Stage Display Client 0.1.4 on the test PC. In the client Setup, choose **11 - TEST ONLY**, use the controller URL `http://CONTROL-PC-IP:3174`, and select the test PC's player/stage monitors. Save and reconnect.

The controller shows Station 11 separately labeled **TEST ONLY**. Its per-station mode buttons control only that client. Each graphic has **Test 11: Full graphic** and **Test 11: Wall slice** controls. Select a slice number before testing a wall graphic; five-screen graphics offer slices 1–5. Test playback starts immediately without the shared stage cue.

Global modes, ordinary wall presets, and bulk client updates continue to target stations 1–10. Test playback does not replace or fire the stage's prepared preset. Station 11 is excluded from the ten-station online count. Existing stage clients can remain on 0.1.3; only the test client needs 0.1.4 to select Station 11.

If the test client runs on the controller PC, its Stage Display setting still opens fullscreen on the selected monitor. Choose a monitor that is not carrying a live Program output.
