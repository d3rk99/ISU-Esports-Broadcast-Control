04 / STREAM DESTINATIONS

Generic RTMP / RTMPS destinations: paste the server URL (e.g. rtmps://live.twitch.tv/app) and put the stream key in the key box, or paste one full URL with the key inside it (rtmps://live.twitch.tv/app/live_xxx) and leave the key box empty. Every destination sends the same encoded program (no extra encoding).

Saving input, encoder or delay changes stops outputs and refills the buffer. Destination-only edits keep the buffer.
